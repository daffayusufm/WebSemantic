# Website Semantic
Repository ini berisi kode website blog Sistem Informasi yang dibuat dengan struktur web semantic sesuai tugas mata kuliah Pengembangan Aplikasi Website. Website ini menampilkan artikel utama, daftar artikel terbaru, dan artikel populer, serta menerapkan elemen HTML5 semantic seperti <header>, <nav>, <main>, <aside>, dan <footer> untuk meningkatkan aksesibilitas dan struktur kode yang lebih terorganisir.

Tampilan website dibuat mirip dengan blog Sistem Informasi Telkom University Surabaya, menampilkan berita dan informasi akademik secara rapi.
